# Bug25: Dify 检索质量——知识库有但答不上来（2026-07-28）

## 症状

日志显示 `[Dify] 老师甲 → 200`（Dify 调用成功），但用户问知识库里明明有的具体案例，AI 回答的是泛化原理而非具体案例内容。

**典型场景**：
- 用户问："左脚红肿疼痛（PPTX补充案例）"
- AI 答："根据经络理法，可以从以下几个方面..."（泛化原理，非具体案例）

## 根因

Dify 的 RAG 检索是**语义相似度匹配**，不是精确查找。即使知识库里有这个案例，如果：

1. 案例的 chunk 标题/内容与 query 语义相似度不够高
2. chunk 被分割后，关键案例内容散落在不同段落
3. top_k 召回只取了最相关的几段，相关度略低的案例被过滤

→ LLM 只能基于检索到的片段生成，答不出具体案例

## 诊断方法

**在 Dify Studio 日志里查看「检索到」的文档片段**：

1. 打开 Dify Studio → 老师甲 App → 「日志」标签
2. 点开这次对话
3. 展开「检索到」面板
4. 看召回的 chunk 是不是你期望的那个案例

**如果检索到的不是目标案例** → 问题在 chunk 分割或 query 语义匹配

**如果检索到但回答不对** → 问题在 LLM prompt 或知识库内容质量

## 修复方向

| 情况 | 修复方法 |
|------|---------|
| 案例被分割太散 | 重新上传，用 `## 案例标题` 大段不分隔 |
| query 匹配不上 | 在知识库文档里加关键词标签 |
| top_k 太小 | Dify App 设置里调高检索数量 |
| 案例根本没索引 | 确认 `document_segments.index_node_id` 非空 |
